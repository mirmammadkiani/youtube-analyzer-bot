# 🎬 ربات تلگرام تحلیلگر هوشمند ویدیوهای یوتیوب

یک ربات پیشرفته تلگرام مبتنی بر **Cloudflare Workers** و هوش مصنوعی **Google Gemini** برای تحلیل، خلاصه‌سازی و شرح صحنه‌به‌صحنه ویدیوهای یوتیوب به زبان فارسی.

---

## ✨ قابلیت‌های کلیدی

- ⚡️ **سه حالت پردازش هوشمند:**
  1. `خلاصه کوتاه و سریع`: استخراج موضوع و چکیده در ۲ الی ۳ پاراگراف فشرده.
  2. `تحلیل کامل و جامع`: بررسی مو به مو به همراه استدلال منطقی مرحله‌به‌مرحله (Chain of Thought).
  3. `شرح ویدیو`: روایت داستانی و صحنه‌به‌صحنه رخدادها با تایم‌استمپ‌های کلیک‌پذیر متصل به ثانیه دقیق ویدیو در یوتیوب (تحلیل فریم‌به‌فریم تا ۵۰ دقیقه با توزیع زمانی متوازن از ابتدا تا انتهای ویدیو).
- 🧠 **فرمت‌بندی مدرن تلگرام (Artificial Features):**
  - استفاده از `<blockquote expandable>` برای کادر تاشو و مخفی‌شونده استدلال و شناسنامه ویدیو.
- 💾 **کشینگ نتایج در Cloudflare KV (کاهش ۱۰۰٪ هزینه توکن):**
  - ذخیره تحلیل‌ها به مدت ۳۰ روز و تحویل آنی (زیر ۵۰ میلی‌ثانیه) در درخواست‌های تکراری بدون مصرف حتی ۱ عدد توکن.
- 💬 **پشتیبانی از پیام‌های چندبخشی (Message Chunking):**
  - تحلیل ویدیوهای طولانی بدون قطع شدن یا بریدن متن، به صورت خودکار در چند پیام پیوسته ارسال می‌شود.
- 🛡 **پنل مدیریت و امنیت پیشرفته:**
  - سیستم تایید دسترسی کاربران (Whitelist).
  - آمارگیری مصرف روزانه و تفکیکی کلیدهای جمنای.
  - ارسال پیام همگانی (Broadcast).
  - ثبت لاگ‌های سیستمی و خطایابی.
  - امکان ثبت درگاه دونیت / حمایت مالی.

## 🚀 راهنمای نصب و راه‌اندازی گام‌به‌گام

### ۱. پیش‌نیازها
- نصب [Node.js](https://nodejs.org) (نسخه ۱۸ یا بالاتر)
- دریافت توکن ربات تلگرام از [@BotFather](https://t.me/BotFather)
- دریافت کلیدهای رایگان Gemini API از [Google AI Studio](https://aistudio.google.com/)
- یک حساب کاربری در [Cloudflare](https://dash.cloudflare.com/)

---

### ۲. پیکربندی کلیدها و امنیت (Secrets)

کلیدهای محرمانه هرگز در سورس‌کد قرار نمی‌گیرند و از طریق **Cloudflare Secrets** یا فایل محلی `.dev.vars` مدیریت می‌شوند:

```bash
# تنظیم توکن ربات تلگرام
npx wrangler secret put TELEGRAM_TOKEN

# تنظیم شناسه عددی ادمین
npx wrangler secret put ADMIN_ID

# تنظیم کلیدهای هوش مصنوعی جمنای (به صورت آرایه JSON یا با ویرگول)
npx wrangler secret put GEMINI_KEYS
```

برای توسعه محلی نیز می‌توانید فایل `.dev.vars.example` را به `.dev.vars` کپی کرده و متغیرهای خود را در آن وارد کنید.

---

### ۳. ساخت دیتابیس KV در کلودفلر

در ترمینال، دستور زیر را برای ورود به اکانت کلودفلر اجرا کنید:
```bash
npx wrangler login
```

سپس یک فضای ذخیره‌سازی KV برای ربات ایجاد کنید:
```bash
npx wrangler kv namespace create BOT_KV
```

خروجی شبیه به این به شما داده می‌شود:
```toml
[[kv_namespaces]]
binding = "BOT_KV"
id = "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
```

مقدار `id` دریافتی را در فایل `wrangler.toml` به جای `YOUR_KV_NAMESPACE_ID` قرار دهید.

---

### ۴. استقرار روی کلودفلر (Deploy)

دستور زیر را در پوشه پروژه اجرا کنید:
```bash
npx wrangler deploy
```

پس از اتمام، یک آدرس دامنه اینترنتی به شما داده می‌شود (مثلاً `https://youtube-analyzer-bot.yourname.workers.dev`).

---

### ۵. تنظیم وبهوک تلگرام (Webhook)

آدرس وبهوک تلگرام را با قرار دادن توکن ربات و آدرس ورکر خود تنظیم کنید:
```bash
curl -F "url=https://YOUR_WORKER_URL.workers.dev" https://api.telegram.org/botYOUR_TELEGRAM_BOT_TOKEN/setWebhook
```

تبریک! ربات شما با موفقیت فعال شد. 🎉

## 🔄 استقرار خودکار با GitHub Actions (CI/CD)

این مخزن به صورت خودکار با هر کامیت بر روی شاخه `main` روی کلادفلر دیپلوی می‌شود. برای فعال‌سازی در مخزن گیت‌هاب خود:

1. به بخش **Settings > Secrets and variables > Actions** در گیت‌هاب بروید.
2. دو سکرت زیر را ایجاد کنید:
   - `CLOUDFLARE_API_TOKEN`: توکن دسترسی کلادفلر با دسترسی ویرایش ورکرها.
   - `CLOUDFLARE_ACCOUNT_ID`: شناسه اکانت کلادفلر شما.
